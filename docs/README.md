FearX-Chat is a full replacement for the default FiveM chat, built for PvP and RP servers. It ships with proper channels, RP commands, cosmetic name tags and avatar decorations, a staff panel and auto-moderation that works out of the box. It provides `chat`, so every script built for the default chat keeps working with zero changes.

Server owners get full control over who can say what and where. Every message is validated server-side, slurs, IP loggers, Discord invites and spam are blocked before anyone sees them, and repeat offenders are muted automatically. Staff can lock channels, set slow mode, clear chat and mute players from one panel. It works on ESX Legacy, QBCore and QBox out of the box and runs standalone without a framework.

Key Features

* Channels: Local (proximity), OOC, Advertise, Staff and Announcements, all configurable
* RP Commands: `/me`, `/do`, `/ooc`, `/w`, `/ad`, `/clear` and `/chatsettings`, renameable or removable
* 5 Chat Styles: Cards, Bubbles, Minimal, Compact and Feed, picked per player
* Name Tags: up to 3 per player, with shine, glow, pulse, flow and ring effects
* Avatar Decorations: 12 included, unlocked through cosmetic packs
* Cosmetic Packs: unlocked with ACE permissions, ready to sell on Tebex
* Discord Avatars: shown next to every message, cached
* Job Tags: LSPD and EMS badges that only show while on duty
* Character Names: pulled from ESX, QBCore or QBox
* Auto-Moderation: slur filter with allow-list, IP logger blocking, Discord invite and IP address blocking, link allow-list
* Anti-Spam: burst and duplicate detection with automatic mutes
* Staff Panel: announcements, channel lock, slow mode, clear all, timed or permanent mutes
* Persistent Mutes and Profiles: saved across restarts, no database needed
* Live Moderation Settings: admins change filter settings in game, no restart
* Default Chat Compatible: `chat:addMessage`, `chat:addSuggestion`, `exports.chat` and friends all work
* Fully Configurable Locales: every player-facing string is editable
